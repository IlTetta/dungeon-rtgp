Three ways a prop attaches

Every prop's origin sits at a deliberate point so your spawner can position it with a single transform. Match the prop's pivot type to the surface you're placing it on.

Floor

Origin at base center. Set it on the floor point; any yaw works. 8 of 10 props.

Wall torch

Origin at the wall contact (back-plate base). Align its back to the wall normal, mount ~1.9u up.

Hanging chain

Vertical segment, origin at the lower end. Offset so the top meets the ceiling anchor, or rotate 180°.

Wiring it up

From spawner to screen

  • Load the OBJ, bind <name>_albedo.png as base color. Add _normal (OpenGL +Y) and _roughness on the same UVs when your PBR path is ready.
  • Textures upside-down? Flip V in the loader — stbi_set_flip_vertically_on_load(true).
  • Brazier & torch are lights. Spawn a warm point light (~1800K) + an animated flame billboard at the fire. The baked embers carry the glow.
  • Colliders: box / cylinder / capsule from the bounding box — never the raw mesh, above all not the 85k statue.
  • Everything shares scale: the column's 3u height is your room height — size rooms around it.
Credit the statue. It's a museum photoscan — Mourner from the Tomb of Philip the Bold (Scan the World), almost certainly CC-BY. Name the source in your report and in-game credits. 
// engine-agnostic spawn sketch
void placeFloorProp(Prop p, vec2 cell) {
  vec3 pos = floorPoint(cell);      // origin = base center
  float yaw = random(0, TWO_PI);
  spawn(p, pos, yaw);
}

void placeTorch(vec3 wallPt, vec3 wallN) {
  vec3 pos = wallPt + wallN*0.0;    // origin sits on the wall
  float yaw = atan2(wallN.x, wallN.z);
  pos.y = 1.9;
  spawn("torch", pos, yaw);
  addPointLight(pos + up*0.2, WARM); // + flame billboard
}

// rubble: cheap, scatter it
for (i = 0; i < n; i++)
